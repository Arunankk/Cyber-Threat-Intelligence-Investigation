# Cyber Threat Intelligence Investigation and IOC Analysis

## Project Overview

This project focuses on conducting a practical Cyber Threat Intelligence (CTI) investigation using publicly available threat intelligence sources and OSINT techniques.

The investigation examines a real-world ClickFix social engineering campaign delivering Vidar Stealer malware.

## Objectives

- Collect and classify Indicators of Compromise (IOCs).
- Investigate IP addresses, domains and file hashes.
- Compare intelligence from VirusTotal, AbuseIPDB and AlienVault OTX.
- Perform OSINT investigations using WHOIS, DNS and SSL/TLS records.
- Identify malware families and possible attacker techniques.
- Correlate related indicators and map activities to MITRE ATT&CK.
- Prepare an evidence-based threat intelligence report.

## Tools and Technologies

- VirusTotal
- AbuseIPDB
- AlienVault OTX
- WHOIS
- DNSDumpster
- MITRE ATT&CK
- CyberChef
- Microsoft Excel

## Investigation Status

Phase 1 – Threat Intelligence Collection: In Progress.

Initial research indicators have been identified from a publicly available incident investigation. All indicators will undergo independent validation before final classification.

## Disclaimer

This project is intended for cybersecurity education and defensive threat intelligence research. Only publicly available intelligence sources and passive investigation techniques are used. Malware samples are not executed, and suspicious infrastructure is not accessed directly.
